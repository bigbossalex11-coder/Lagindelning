# Lagindelning

Appens funktion är att den ska fungera som ett verktyg för att dela in lag inför träningar. Det ska fungera både som en randomizer och ett nivåindelnings system.

## Köra lokalt

```
git clone https://github.com/bigbossalex11-coder/Lagindelning.git
cd Lagindelning
npm install
npm run dev

```

Öppna adressen som terminalen visar: http://localhost:5173 I webläsaren
